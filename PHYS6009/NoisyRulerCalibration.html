Detector response model: s = x_true + α·sin(2π·x_true / L) + ε   where   ε ~ 𝒩(0, σ_noise²).
The sinusoidal term is a systematic nonlinearity — a deterministic warp of the position axis (e.g. non-uniform strip pitch). The ε term is stochastic readout noise. Both broaden and distort the signal histogram compared to x_true. Set α=0 and σ=0 to confirm the response curve collapses to the identity line.

Calibration procedure: A calibration source fires N_cal particles at each of 9 known reference positions x_ref ∈ {10, 20, …, 90} mm. The detector sees these through the same response model s = x_ref + α·sin(2π·x_ref/L) + ε. The mean measured signal at each reference point gives 9 (s̄, x_ref) pairs. A degree-p polynomial is fitted to these pairs via least-squares (normal equations), giving the correction map x_reco = f(s). This map is then applied to all physics events. Watch how residuals shrink as you raise the polynomial order — but also watch for overfitting artefacts near the edges when order is high relative to the 9 calibration points.

Independent validation: A source at 75 mm — not used during calibration — fires N_val events through the same detector response. The calibration correction from Stage 3 is applied (if it exists). The reconstructed mean μ_reco should ideally equal 75 mm. The bias Δ = μ_reco − 75 mm measures how well the calibration interpolates between the two bracketing reference points (70 and 80 mm). The pull Δ/σ expresses the bias in units of the peak resolution — values near zero indicate a good calibration; large values indicate residual systematic error. Try changing the detector params in the banner after calibrating to watch the bias grow.
